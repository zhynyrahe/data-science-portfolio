Run `python3 color_trend_analysis.py` from the project root to generate all charts in this folder.

Generated files:
  - color_timeline.png     : Line chart of each color family's sales trend (2019–2024)
  - seasonal_heatmap.png   : Heatmap of average sales by season and color
  - momentum_scores.png    : Horizontal bar chart of linear regression momentum scores
  - forecast_2025.png      : Top 5 projected colors for the next season (2025)
