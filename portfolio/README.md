## Projects

### 1. [Color Trend Analysis — Fashion Retail](./color-trend-analysis/)

**What it does:** Analyzes six years of synthetic fashion sales data to identify which color families are gaining momentum, which are declining, and what the next season should invest in.

**Key techniques:** Exploratory data analysis, linear regression trend scoring, time-series pivots, 2025 color forecasting.

**Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

**Highlights:**
- Sage Green and Lavender emerged as the highest-momentum colors (2019–2024)
- Slope-based momentum scoring ranks colors by trajectory, not just volume
- Top 5 colors for 2025 forecasted using per-color LinearRegression models

---

### 2. [Customer Purchase Prediction — Fashion E-Commerce](./customer-purchase-prediction/)

**What it does:** Builds a binary classifier to predict whether a fashion e-commerce visitor will convert to a buyer, using behavioral signals from their browsing session.

**Key techniques:** Random Forest classification, class balancing, feature importance analysis, conversion rate segmentation.

**Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`

**Highlights:**
- Cart-add behavior is the dominant predictor — outweighing demographics
- 25–34 and 35–44 age groups convert at the highest rates across all categories
- Outerwear drives the highest category-level conversion rate

---

### 3. [A/B Test Analysis — Fashion Email Campaign](./ab-testing-analysis/)

**What it does:** Simulates a subject line A/B test for a fashion brand's email campaign, rigorously evaluates statistical significance, and delivers a deployment recommendation.

**Key techniques:** Two-proportion z-test, confidence intervals (Wilson score), Cohen's h effect size, z-distribution visualization.

**Libraries:** `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`

**Highlights:**
- Social-proof subject line outperformed control by 2.6 percentage points
- Result is statistically significant (p < 0.05) with a clear 95% CI
- ~130 additional conversions per 5,000-send campaign attributable to subject line alone

## How to Use This Portfolio

Each project is self-contained. To run any of them:

```bash
cd <project-folder>
pip install -r requirements.txt
python3 <script_name>.py
```

Charts are saved automatically to each project's `sample_output/` directory. No external data download required — all datasets are generated by the scripts.
